# 회의실 — AI 토큰 없는 공동 제작회의 웹앱

계정·가입 없이 **회의실 만들기 → 편집 링크 복사 → 팀원에게 전송**으로 공동 편집할 수 있습니다.

## 주요 기능
- 출연자, 장소·답사, 일정, 회의 기록, 결정 사항, 할 일 탭
- 회의실별 편집 링크와 보기 전용 링크
- 서버 저장 및 약 4초 간격 변경사항 자동 동기화
- **PPT 제작실:** 탭별 내용 선택 후 편집 가능한 PPTX 다운로드 (텍스트·도형, 페이지당 최대 4항목)
- JSON 백업 다운로드
- OpenAI API 없음, AI 토큰 소모 없음, 외부 npm 패키지 없음

## 컴퓨터에서 실행
Node.js 20 이상 설치 후 폴더 안에서:

```bash
npm start
```

브라우저에서 `http://localhost:3000` 열기.

**주의:** localhost 링크는 다른 사람에게 공유할 수 없습니다. 팀원이 인터넷에서 접속하려면 웹 서버를 공개 배포해야 합니다.

## 실제 팀원과 공유하기
이 폴더를 GitHub 저장소에 올린 뒤, Docker를 지원하는 호스팅 서비스(Render, Railway, Fly.io, VPS 등)에 배포하세요. 서비스에 persistent volume(영구 디스크)을 연결하고 환경변수 `DATA_DIR`을 **해당 디스크 경로**로 지정해야 합니다. `PORT`는 호스팅 서비스가 자동 지정하는 값 사용. HTTPS 도메인에서 공유 링크를 발급하면 됩니다.

도커 자체 실행 예:

```bash
docker build -t team-meeting-room .
docker run -d -p 3000:3000 -v meeting-data:/app/data --name meeting-room team-meeting-room
```

실제 공개 서비스에서 사용자 데이터와 회의 링크를 보호하려면 HTTPS, 접근 제한, 정기 백업, 인증/권한 회수 기능을 추가하는 것이 권장됩니다.

## 설계상 제약
- 로그인 없는 링크 기반 접근이므로 편집 링크를 알면 누구나 수정·삭제 가능. 비밀 링크를 외부에 공개하지 마세요.
- 동시 편집은 서로 다른 항목에 안전하게 반영되나, **같은 항목을 두 사람이 동시에 편집하면 마지막으로 저장한 내용이 우선**합니다.
- 생성 직후 보기 전용 링크를 별도로 보관하세요. 현재 버전은 보기 전용 링크 재발급 화면이 없습니다.
- 웹서버를 여러 인스턴스로 늘리기보다는 단일 인스턴스와 영구 디스크를 사용하세요. SQLite/DB나 로그인은 향후 개선 대상입니다.
- 호스팅 비용이나 도메인 비용이 발생할 수 있지만 AI API 토큰 비용은 없습니다.

## PPT 제작 방식
상단 **PPT 제작** 버튼 → 포함할 탭 체크 → **편집 가능한 PPTX 다운로드**. 전부 서버 내 규칙 기반으로 생성하며 AI API를 호출하지 않습니다. 슬라이드의 텍스트와 도형은 PowerPoint에서 직접 수정할 수 있습니다. 긴 본문은 슬라이드 공간에 맞춰 일부만 표시되므로 발표용으로 편집해 주세요.
