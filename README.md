# 회의실 · GitHub 배포판

**실제로 실행되는 공동 회의실 웹사이트. AI API 키/토큰 불필요.**

## 사용 기능
- 회의실 만들기, 링크로 공동 편집/읽기 전용 공유
- 회의 기록 · 출연자 · 장소/답사 · 일정 · 결정 사항 · 할 일
- 항목 추가/수정/삭제 · 검색 · 약 4초마다 다른 참여자의 변경사항 확인
- 최근 접속한 회의실 목록(개별 브라우저에 저장)
- 원클릭 편집 가능한 PPTX 생성, 섹션 체크박스 선택
- JSON 백업

## 1. 내 컴퓨터에서 확인
Node.js 20+ 설치 후:

```bash
npm start
```

http://localhost:3000 에 접속합니다. 외부 npm 패키지가 없습니다.

## 2. GitHub에 올리기
1. GitHub에서 빈 저장소(`meeting-room`)를 만들고 **Private**로 설정
2. 이 폴더의 파일과 `public` 폴더를 저장소 **최상위**에 업로드 (`server.js`, `package.json`, `render.yaml`이 바로 보여야 함)
3. GitHub 저장소를 Render 서비스에 연결

## 3. Render 배포 (영구 저장 추천)
Render 대시보드에서 **New > Blueprint**를 선택하고 GitHub 저장소를 연결합니다. 저장소 최상위 `render.yaml`을 읽어 Node 웹 서비스와 **영구 디스크**를 구성합니다. 유료 Starter 플랜 및 디스크 비용이 발생할 수 있습니다. 배포 후 Render에서 발급된 `https://...onrender.com` 주소로 접속합니다.

**중요:** Render의 일반 무료 웹 서비스 파일 저장소는 영구적이지 않습니다. 무료 배포 테스트만으로 중요한 회의 기록을 저장하지 마세요. 무료로 운영할 경우 외부 영구 데이터베이스 연동 등의 추가 개발이 필요합니다.

## 4. 팀원과 사용
1. 사이트에 접속하여 회의실 생성
2. `공유 링크` 버튼에서 **편집 링크**를 팀원에게 전달 (보기만 할 사람에게는 보기 전용 링크)
3. `PPT 제작` 버튼 → 포함할 탭 선택 → `.pptx` 다운로드

## 보안 및 제약
- 링크가 비밀번호 역할을 합니다. **링크를 아는 사람은 해당 권한으로 접속**할 수 있고, 편집 링크를 아는 사람은 삭제할 수도 있습니다. 외부 공개 금지. 기업 비밀정보는 별도 로그인/관리자 관리 기능이 준비되기 전까지 입력하지 마세요.
- 여러 사용자가 **같은 항목을 동시에 편집하면 마지막으로 저장한 내용이 남습니다.**
- 프로젝트 전체 검색·파일 업로드·실시간 커서 수준의 공동 편집 기능은 없습니다.
- 기록은 서버의 `DATA_DIR`에 JSON 파일로 저장됩니다. 서비스 장애나 실수 삭제에 대비해 정기적으로 JSON 백업을 받으세요.
- AI API 토큰은 0이지만 **호스팅/영구 저장 비용은 별도**입니다.
