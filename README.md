# 회의실 — 간편 공유 버전

기존 간편판의 프로젝트 개요·회의록·출연진·장소·일정·결정사항과 편집 가능한 PPTX 생성 기능을 그대로 두고, **링크를 가진 팀원 간 내용 공유** 기능을 더했습니다. AI API, API 키, AI 토큰은 필요 없습니다.

## 실행하기

Node.js 20 이상에서:

```sh
npm start
```

브라우저에서 `http://localhost:3000` 접속. 새로운 회의실이 생기며 주소에 `?room=...&key=...`가 추가됩니다. 상단 **🔗 공유 링크** 버튼으로 이 전체 주소를 복사해 팀원에게 보냅니다. 모든 팀원은 동일한 인터넷 서버에 접속해야 합니다. `localhost` 링크는 다른 컴퓨터에서는 동작하지 않습니다.

## 공개 주소 받기

1. 이 폴더의 내용을 GitHub 저장소 루트에 업로드합니다 (`server.js`, `public/`, `render.yaml` 포함).
2. Render → New → Blueprint → 저장소 연결 → 배포합니다.
3. Render가 발급한 `https://...onrender.com` 주소를 열어 회의실을 생성합니다.
4. 상단 공유 버튼으로 팀원에게 복사한 주소를 전달합니다.

**주의:** `render.yaml`의 무료 플랜은 배포/재시작 시 JSON 데이터가 유실될 수 있으므로 테스트 전용입니다. 실제 제작팀에서 장기간 쓰려면 영구 스토리지(유료 영구 디스크, `DATA_DIR=/var/data` 설정 등)가 필요합니다. 보안에 민감한 회의라면 링크 외에 인증·권한 관리도 추가해야 합니다.

## 사용 방법

- 프로젝트별 회의 내용 수정은 자동 저장(약 1초 후)됩니다.
- 열려 있는 다른 팀원의 화면은 약 3.5초 간격으로 변경 여부를 확인합니다. 입력 중에는 화면이 불시에 바뀌지 않도록 새로고침을 피합니다.
- **PPT 만들기** → 포함할 페이지 선택 → PowerPoint에서 개별 글자·도형 편집 가능한 PPTX 다운로드.
- **백업** → JSON 파일 저장. GitHub에는 회의 내용이 저장되지 않습니다.
- 동시 변경 시 이전 내용을 덮어쓰지 않도록 충돌 경고가 표시되며, 현재 내용을 백업한 뒤 새로고침해야 합니다. Google Docs식 동일 문서 실시간 공동 타이핑은 아닙니다.
- 링크에 접근 비밀키가 포함되어 있으므로 외부에 공개하지 마세요. 링크를 가진 사람은 모두 편집할 수 있습니다.

## 개발/저장 구조

- `public/` — 정적 화면·PPT 제작. 기존 간편판 UI.
- `server.js` — 외부 라이브러리 없이 동작하는 Node.js 공유 서버.
- `data/` — 회의실별 JSON 파일. 서버 관리자가 보관해야 합니다.
- `render.yaml` — Render Blueprint 초기 설정.

외부 AI 서비스 호출은 없습니다. PPT는 브라우저에 포함된 라이브러리로 생성합니다.
